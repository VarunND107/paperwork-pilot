# Paperwork Pilot

A life-event bureaucracy navigator for India (Bengaluru first). Describe a situation ("my father
passed away", "moving to Bengaluru with a toddler", "starting a small business") and get an ordered,
dependency-aware checklist. Each step shows the form, documents, office or portal, fee, typical
wait, deadline and what must be done before it.

> **Guidance, not legal advice.** All data in this repository is **sample data** (`verified = false`)
> until someone checks it against the official source.

Work in progress. The full handoff (how to run, verified vs sample, next steps) is written at the end
of the build.

## Quick start

- **Windows:** double-click `start.bat` (needs Docker Desktop).
- **macOS / Linux:** `./start.sh` (needs Docker).

Then open <http://localhost:8080>.
